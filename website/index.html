Take it with you

Works on your phone, too.

Once hosted on HTTPS, install Mistral Chat from your mobile browser. It opens like an app and keeps the same responsive chat experience.

On iPhone: open in Safari, tap Share, then Add to Home Screen.
On Android: open in Chrome, tap the menu, then Install app.
